# 实习领航 · 求职中台

一款面向求职同学的「实习投递一站式」客户端应用，围绕你的两个职业方向（泛体制内：央国企投资/财务、银行非柜台；券商：债承/卖方研究/直投）提供从信息收集、进度管理到能力提升、简历优化的全流程支持。

## 核心功能

### 一、实习投递追踪（核心）
- 内置**实习推荐库**：结合你的两个方向整理的方向性机会（中投/国新、工农中建总行、政策性银行、中信/中金/华泰/国君等），一键加入投递列表。
- **JD 智能解析**：粘贴招聘信息，AI 自动提取岗位、要求、投递方式等结构化字段。
- **手动添加**：自由记录机构、方向、截止日期、投递渠道。
- **投递流水线看板**：想投 → 已投递 → 笔试 → 面试 → Offer → 拒信，可视化跟踪每个机会的进展。
- **详情管理**：状态流转、备注、联系人、进展记录。

### 二、能力培养与学习推送（核心）
- **AI 能力匹配分析**：基于你选择的目标岗位/综合方向，结合你的背景（西南财大金融科技、五矿证券债承、华创证券计算机组、恒丰银行对公、华发财务等），输出能力差距清单（已掌握 / 学习中 / 缺口）。
- **AI 推送学习资料**：为每项能力推送 3-5 条可落地的学习路径（课程、书籍、报告、工具），并支持勾选完成度。

### 三、简历优化
- **多版本简历管理**：基于你上传的简历生成初始版本。
- **按方向 AI 优化**：针对「泛体制内」或「券商」输出问题诊断 + STAR 量化改写示例 + 方向化建议。

### 四、AI 求职助手
- 多会话对话，内置 4 个领域 Agent：求职总教练、实习推荐官、能力规划师、简历优化师。
- 流式 Markdown 回复。

### 五、设置
- 个人档案编辑（方向、兴趣行业、技能）。
- CodeBuddy API Key 配置（启用 AI 功能）。
- 数据本地导出 / 导入 / 重置。

## 技术说明
- 前端：React 19 + Vite + Tailwind + shadcn/ui（数据存于浏览器本地，符合"客户端应用"）。
- 后端：Express + CodeBuddy Agent SDK（AI 能力由 SDK 驱动，需要 API Key）。
- 桌面封装：提供 Electron 配置（见 `electron/`），先以 Web 浏览器开发。

## 使用前提
AI 相关功能（能力匹配、学习推送、简历优化、对话）需要在「设置」中配置 CodeBuddy API Key，或在后端 `.env` 填写 `CODEBUDDY_API_KEY`。
